# KingofNothing07

AI skills for high-fidelity inheritance, semantic testing, market scouting, and honest project design.

Each skill is a single self-contained Markdown file. Install by copying the entire file and pasting it into any AI that accepts system prompts, custom instructions, project knowledge, or skill uploads.

## Skills

### [Semantic Shorthand](https://github.com/KingofNothing07/Semantic-Shorthand)
High-fidelity, low-token inheritance logs that survive across sessions, models, and agents. Capture decisions, relationships, conditionals, dependencies, and outcomes so later readers continue without rediscovery or summarization loss.

**Files:**
- Full package — complete language, logging, curation, inheritance, and Coding Mode
- Fully capable lite version (lower token cost, equivalent power)
- Language & Grammar only
- Logging, Curation & Inheritance practice only

**Install:** Copy any Semantic Shorthand file from the repo.

### [FaCD — Factored Context and Discernment](https://github.com/KingofNothing07/FaCD-logic-engine)
Algebraic test of semantics. Write claims, plans, or options as `Left = Right`, factor both sides in public, tag the result, and leave a page anyone can rerun. Standalone or companion to Semantic Shorthand (shared notation).

**Includes:** Full skill package, Language Core reference, and Solutions Library (community examples welcome via PR).

**Install:** Copy `01.01_FaCD-Factored_Context_and_Discernment-Skill_Package.md`.

### [Market Scout Mentor](https://github.com/KingofNothing07/Market-Scout-Agent)
Gated fair-value scouting for stocks and crypto using custom fair-value equations.

**Install:** Copy `Market-Scout-Mentor.md`.

### [Project Mentor](https://github.com/KingofNothing07/Project-Mentor-Brainstorm-to-Build-Anything)
Honest design mentor that turns a rough idea into an approved, agent-ready project log and inheritance document. Supports software, systems, businesses, skills, books, and more.

**Install:** Copy `SKILL.md`.
