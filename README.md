# KingofNothing07

AI skills for high-fidelity inheritance, semantic testing, market scouting, and honest project design.

Each skill is a single self-contained Markdown file. Install by copying the entire file and pasting it into any AI that accepts system prompts, custom instructions, project knowledge, or skill uploads.

## Skills

### [Semantic Shorthand](https://github.com/KingofNothing07/Semantic-Shorthand)
High-fidelity, low-token inheritance logs that survive across sessions, models, and agents. Capture decisions, reasoning, relationships, conditionals, dependencies, and outcomes so a later reader can continue without rediscovery or summarization loss. Only approved material enters the main log; compression re-encodes rather than discards sacred content.

**Includes:** Full package, fully capable lite version, Language & Grammar reference, and Logging/Curation/Inheritance practice document. Coding Mode for software design is included in the full and lite packages.

**Start here:** The repository README is a full user guide covering purpose, abilities, how/why to use, file choices, and AI install instructions.

### [FaCD — Factored Context and Discernment](https://github.com/KingofNothing07/FaCD-logic-engine)
Algebraic test of semantics. Write a claim, plan, option set, testimony, or staged goal as `Left = Right`, factor both sides in public, tag the result (True / False / Unsolved / Unknown), and leave a page anyone can rerun. Standalone or companion to Semantic Shorthand (shared Language Core notation).

**Includes:** Full skill package, Language Core reference, and Solutions Library (community examples welcome via PR).

**Start here:** The repository README is a full user guide covering purpose, abilities, how/why to use, activation notes, and AI install instructions.

### [Market Scout Mentor](https://github.com/KingofNothing07/Market-Scout-Agent)
Gated fair-value scouting for stocks and crypto using custom fair-value equations.

**Install:** Copy `Market-Scout-Mentor.md`.

### [Project Mentor](https://github.com/KingofNothing07/Project-Mentor-Brainstorm-to-Build-Anything)
Honest design mentor that turns a rough idea into an approved, agent-ready project log and inheritance document. Supports software, systems, businesses, skills, books, and more.

**Install:** Copy `SKILL.md`.
